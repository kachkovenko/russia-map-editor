# Редизайн редактора · 18 сентября 2026

## Направление

Ориентир — предоставленный пользователем `ref.webp`: спокойная светлая доска, белые инструменты, точная сетка, сдержанная типографика, один синий акцент. Интерфейс остаётся редактором карты, без декоративных пунктов навигации и неработающих элементов «скоро».

- Верхняя панель: документ, история действий, импорт и экспорт.
- Слева: библиотека регионов и городов, поиск (с любой вкладки ищет сразу и регионы, и города), фильтры и выбранные объекты.
- В центре: холст с переключателем вида и отдельной панелью масштаба.
- Справа: единая прокручиваемая панель с раскрывающимися разделами «Вид карты», «Заливка», «Освещение», «Границы», «Подписи и маркеры», «Связи городов», «Слайд». В «Вид карты» собраны отображение, проекция и положение.
- До 1000 px боковые панели открываются кнопками в шапке; на телефоне шапка компактнее.

По обратной связи пользователя вкладки убраны отдельным коммитом; остальное оформление сохранено. Разделы раскрываются независимо, Alt-клик по заголовку сворачивает или раскрывает все сразу. Состояние разделов сохраняется локально и не влияет на файл проекта или историю изменений карты. Существующие идентификаторы полей сохранены. Геометрия, формат проекта и алгоритмы экспорта не менялись.

Посмотреть прежнюю версию (сначала сохранить или закоммитить новые незавершённые изменения):

```bash
git switch backup/ui-before-redesign-2026-09-18
```

Вернуться к редизайну:

```bash
git switch design/editor-ui
```

Для отмены отдельного изменения без переписывания истории найдите его через `git log --oneline`, затем выполните `git revert <хеш-коммита>`. При полной отмене редизайна отменяйте UI-коммиты от нового к старому. Ветки хранятся локально: это точка возврата, но не внешняя резервная копия на случай потери диска. Автосохранение карт в браузере не входит в Git — важные карты следует сохранить в JSON.
