Рабочие заметки для следующей сессии. Источник референсов — Refero (MCP-сервер `refero` уже добавлен в локальную конфигурацию проекта, инструменты появляются при старте сессии). Дата составления: 16 сентября 2026.

Единый шрифт Golos Text (JetBrains Mono убран, цифры табличные). Картографическая фурнитура (координаты, градусная сетка, компас, капители секций) сохранена. Ниже — история «атласа на бумаге», актуальны только разделы про Refero и фурнитуру.

## Статус (16 сентября 2026, коммит «Оформление „атлас на бумаге“ и картографическая фурнитура»)

Сделано: п. 1 целиком (Google Sans заменён на Golos Text 400–700, JetBrains Mono для цифр; сетка-миллиметровка; радиусы 4/6; киноварь `#b5462f`; чернильные рамки; капители в заголовках секций), п. 2 — строка статуса, градусная сетка 10°/5° с цветом, стрелка севера, капители регионов (с трекингом в раскладке и `charSpacing` в PPTX), п. 3 — плотные строки со свотчем справа, деления на ползунках.

Отклонения от плана:

- HEX оставлен видимым рядом со свотчем (моно, 11 px), а не спрятан в поповер: для презентаций коды из брендбука вводят руками, и один клик до пикера важнее экономии 50 px.
- Стрелка севера — один тумблер, всегда идёт в экспорт (отдельного режима «только на экране» нет: компас без экспорта бесполезен).
- Капители остаются в весе 700: веб-сабсеты шрифтов подписей статические жирные; вес 500–600 потребует переменных сабсетов всех шести шрифтов (+~300 КБ) и не ляжет в PPTX (`bold` там бинарный).
- Компас окрашен цветом маркеров (`markerColor`) и обведён контуром подписей, чтобы на тёмном слайде не пропадал.

Не сделано: подписи градусов по краям сетки, масштабная линейка (п. 2), тёмная тема (п. 4).

## Как пользоваться Refero в сессии

Инструменты MCP:

- `refero_search_styles` — семантический поиск «стилей»: описание визуального языка реального сайта с токенами (палитра, шрифты, радиусы, отступы, do/don't). Лучшая отправная точка для визуального направления.
- `refero_get_style` — полная карточка стиля по UUID (цвета с ролями, поверхности, типографика, компоненты, north star, «Agent Prompt Guide»).
- `refero_search_screens` — поиск реальных экранов продуктов (по `platform: "web"`); возвращает UUID, сайт, паттерны, элементы, hex-цвета.
- `refero_get_screen`, `refero_get_similar_screens`, `refero_get_screen_image` (`image_size: "full"`) — метаданные, похожие экраны и сам скриншот для визуального анализа.
- `refero_search_flows`, `refero_get_flow` — пользовательские сценарии (для нас менее актуально).

Сервер предлагает скилл `refero-design`: `npx skills add https://github.com/referodesign/refero_skill --skill refero-design`. Ставить только по явному согласию.

## Диагноз текущего UI

Что читается как «универсальный SaaS / сгенерировано»:

- Google Sans как шрифт интерфейса;
- радиусы 9–13 px, белые «пилюли» с мягкими тенями (`--shadow`, `.export-popover`, `.map-controls`, `.selection-bar`);
- фиолетовый акцент `#6d5dfc` (`--accent`, `--accent-soft`), одинаковые тумблеры-переключатели;
- нейтрально-серый холст `#e9e8e4` с точечной сеткой;
- отсутствие каких-либо картографических элементов в «фурнитуре»: ни координат, ни сетки, ни компаса, ни масштаба.

Ключевые места в коде: токены в `:root` ([styles.css](../styles.css), строки 9–24), холст `.stage` и сетка `--grid-*` (задаются в `applyCanvasTransform` в [app.js](../app.js)), панели `.panel-column`, `.section-toggle`, кнопки `.button--*`, поповеры `.export-popover`, оверлеи `#map-selection`, `#lens-focus`, `#active-outline`.

## Рекомендации

### 1. Токены «атлас на бумаге» — сделать первым

Меняет характер сразу, макет не трогает.

- **Холст:** тёплый пергамент `#f2f0e8` (или `#efefe4` из Paper) вместо серого. Вместо точек — тонкая сетка-миллиметровка: минорные линии каждые 16 px `rgba(0,0,0,.04)`, мажорные каждые 64–96 px `rgba(0,0,0,.08)`; сетка по-прежнему едет и масштабируется с доской (`--grid-x/--grid-y/--grid-size`).
- **Радиусы:** 4 px у кнопок, полей, свотчей; 6 px у поповеров; никаких пилюль. Тени убрать, глубина — через 1 px бордеры цвета чернил с низкой альфой (`rgba(23,23,23,.14)`), у панелей — inset-бордер (Operate).
- **Акцент:** один «картографический» вместо фиолетового: киноварь `#b5462f` (границы в старых атласах) либо янтарь Felt `#dc8c46`. Рамки выделения объекта и регионов — чернильно-чёрные `#171717`, а не акцентные. Второй хроматический цвет не вводить (правило Mapbox).
- **Шрифты интерфейса:** Golos Text (уже в проекте, кириллица, русский) для UI-текста; моноширинный (JetBrains Mono или IBM Plex Mono, OFL, положить сабсеты в `fonts/`, записать в `THIRD_PARTY_NOTICES.md`) — для чисел, HEX-кодов, процентов, координат, `16:9 · PNG 3200 × 1800`.
- **Заголовки секций:** капители с трекингом: `ЗАЛИВКА`, `ГРАНИЦЫ И ПОДПИСИ`, 10.5–11 px, `letter-spacing: .12em`, цвет чернил с альфой .7 (NYT/Mapbox).
- **Кнопка «Экспорт»:** чернильная, 4 px радиус, без inset-подсветки; «Импорт» — с 1 px бордером на прозрачном фоне.
- **Тумблеры:** уменьшить (30 × 17), активное состояние — чернильное, не акцентное.

### 2. Картографическая «фурнитура» на холсте

- **Строка статуса** в нижнем углу холста (как в Mapbox Studio): `масштаб карты % │ 55.75° с. ш., 37.62° в. д.` — координаты под курсором через обратную проекцию (`lensBase.invert` / базовая проекция без линзы; для «Линзы» — приблизительно или скрыть). Моно, 11 px, обновлять в `pointermove` с троттлингом.
- **Градусная сетка** (меридианы и параллели): переключатель в разделе «Проекция», шаг 10°/5°, тонкие линии `rgba(23,23,23,.18)`, подписи градусов по краям опционально. Рисовать через `d3.geoGraticule()` внутри `#export-content` (попадает в экспорт), с отдельным цветом и толщиной; в PPTX идёт как часть векторного SVG.
- **Атласные капители для регионов:** режим подписей `«КРАСНОЯРСКИЙ КРАЙ»` разреженными заглавными (`text-transform: uppercase; letter-spacing: .14em`, вес 500–600 вместо 700). Учесть при измерении ширины текста (`textWidth`) и в PPTX (`charSpacing` в PptxGenJS, `text.toUpperCase()`).
- **Стрелка севера** — маленький компас в углу слайда, поворачивается вместе с `state.rotation` через `mapFrame.angle`; переключатель «в экспорт / только на экране».
- **Масштабная линейка** — необязательно: для презентационной карты в равновеликой проекции линейка условна; если делать — только для «Атласной» проекции, считать по `projection` между двумя точками на центральной параллели.

### 3. Панель свойств по образцу Mapbox Studio

- Строка свойства: подпись слева, справа — квадратный свотч 18 × 18 с 1 px бордером; HEX показывать во всплывающем пикере, а не в поле рядом (сейчас `.color-control--wide` занимает 122 px).
- Плотность: высота строки 30–32 px, `elementGap` 8 px, `padding-inline` панели 16 px.
- Ползунки: значения моно, деления (tick marks) для целочисленных диапазонов.
- Группы сворачиваются, заголовок группы — капители из п. 1; шеврон уже вращается вокруг центра.

### 4. Опционально: тёмная тема «ночной пульт»

По Felt/Mapbox: панели графитовые (`#15171b` / `#1c1f24`), холст `#0e1012`, белый слайд — единственный источник света; текст `#a0aaba` для вторичного, `#ffffff` только для заголовков и активных подписей. Сильный образ для редактора карт, но это отдельная тема оформления (`data-theme`), а не правка токенов. Делать после п. 1–3.

1. Токены (п. 1) → скриншот «до/после» в headless Chrome (`--headless=new --screenshot`), сверить контраст текста на пергаменте (AA для 12 px: ≥ 4.5:1).
2. Строка координат и градусная сетка (п. 2) → проверить, что сетка есть в SVG/PPTX-экспорте, а строка статуса и компас-«только экран» удалены в `getExportSvg` (по образцу `#map-selection`, `#lens-focus`).
3. Панель (п. 3) → скриншот панели целиком, проверить отсутствие горизонтального скролла на ширине 320 px.
4. Обновить README («что уже работает»), `THIRD_PARTY_NOTICES.md` (новые шрифты), закоммитить по темам.

Проверка настоящими событиями мыши: скрипты на Chrome DevTools Protocol из прошлой сессии (`Input.dispatchMouseEvent`, `Page.captureScreenshot`) — паттерн описан в истории коммитов `8407e5d` и `5fa0fff`.

## Чего не делать

- Не вводить второй акцентный цвет и градиенты в интерфейсе (карта — единственное цветное).
- Не смешивать радиусы: либо 4/6 px, либо 0.
- Не подключать шрифты с `fonts.googleapis.com` — только локальные `.woff2` (принцип «после загрузки без внешних сервисов», стабильность в РФ, лицензии в notices).
- Не имитировать «старину» текстурами, шумом и рукописными шрифтами — картографичность даётся сеткой, координатами, капителями и моноширинными цифрами, а не декором.
