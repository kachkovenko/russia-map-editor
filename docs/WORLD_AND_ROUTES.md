# Мир, освещение и маршруты

## Как пользоваться

- Слева переключите **Россия / Весь мир**. Россия — прежние 89 регионов; мир — 258 стран и территорий, не 258 суверенных государств. Объекты можно искать и выделять в списке или на карте; поиск находит и страны, и города с любой вкладки. Выбор каждого набора сохраняется при переключении; оформление общее. Переключение охвата сбрасывает положение и проекцию, его можно отменить.
- В разделе **Вид карты → Проекция** выберите **Глобус**. Поверхность включается там же, цвет океана находится в **Заливке** и показывается только для включённой поверхности.
- В разделе **Освещение** независимо регулируются интенсивность освещения, направление света и интенсивность блика. Нулевой блик не выключает освещение. При выключенной поверхности настройки остаются сохранёнными, но временно недоступны. Глобус вращается за ручку в его центре (как 3D-объект в PowerPoint; двойной клик по ручке возвращает исходное положение), **Alt + перетаскиванием** или ползунками долготы и широты обзора в **Вид карты → Положение**; обычное перетаскивание сохраняет навигацию по карте/холсту. На сенсорном экране используйте ползунки обзора.
- **Подписи и маркеры → Оформление → На подложке** включает скруглённые подложки для городов и регионов/стран. Цвет подложки меняется отдельно; текст на подложке тёмный. Работает и в «Атласе», и в «Мозаике».
- **Связи городов** связывают отмеченные города: **Из одного центра** (центр выбирается), **Случайная сеть** (все участники соединены, есть кнопка перестроения), **Цепочка** (порядок выбора, кнопки ↑/↓ для перестановки). Цвет, толщина и тип линии настраиваются. На плоской России регулируется изгиб; на мире и глобусе используются географические дуги, корректно обрезанные по горизонту/шву карты.

## Ограничения и сохранение

- В российском каталоге уже были Березники и Соликамск, оба относятся к Пермскому краю. Наличие проверяется `check:routes`; дубликаты не добавлялись.
- Мировой каталог объединяет российские города и основные мировые города/столицы Natural Earth: 1237 записей в текущей сборке. Это **не все города мира**. Население источника используется лишь для приоритета подписей, не как актуальная статистика.
- Маршруты ограничены первыми 150 выбранными городами; интерфейс предупреждает при превышении. Случайная сеть разреженная, а не все возможные пары; её номер варианта и порядок цепочки сохраняются, поэтому экспорт не меняет рисунок.
- JSON версии **2** сохраняет охват, оформление, свет и связи; номер схемы не менялся для аддитивного поля блика. Проекты v1/v2 со старым единым `globeLight` открываются с прежним визуальным результатом: его значение применяется и к освещению, и к блику. Старый редактор не поддерживает новые проекты v2. Импорт по-прежнему принимает только известные поля, допустимые значения и идентификаторы, размер до 256 КБ. Ссылки, код и HTML не исполняются.
- В SVG/PNG уходят поверхность, свет, подложки и линии. В PPTX карта и подложки остаются в SVG, текст подписей — отдельными редактируемыми объектами. Подложки не являются самостоятельными редактируемыми фигурами PowerPoint. Города за горизонтом не экспортируются как видимые подписи.
- Мир использует ту же территориальную трактовку РФ, что российский режим; остальные границы следуют источнику. Международно спорный статус пояснён в интерфейсе, документации и заметках PPTX. Источники и лицензии: [WORLD_DATA.md](../data/WORLD_DATA.md).

## Проверки

```bash
node --check app.js
npm run check:regions
npm run check:world
npm run check:routes
npm run check:project
git diff --check
```

В Chrome проверены: выбор стран и городов, переключение охвата и проекций, скрытие обратной стороны сферы, мозаика на глобусе, сохранение после перезагрузки, отмена/повтор, три схемы связей и перестановка цепочки. Проверены Alt-перетаскивание, крайняя точка обзора без видимых российских регионов и панели при ширинах 1280, 820 и 390 px. Реально скачаны SVG, PNG 3200 × 1800 и PPTX; проверены SVG-вложение и отдельный редактируемый текст в архиве PPTX. JSON v2 импортирован обратно, v1 — успешно прочитан; недопустимый `routeHub` отклонён без изменения карты. Сам PowerPoint не запускался; Safari/Firefox отдельно не проверялись.

## Откат

Ветка разработки — `design/editor-ui`. Состояние до этой серии изменений сохранено в `backup/before-world-routes`. Это локальная точка возврата, не внешняя резервная копия.

Подложки и схемы связей — отдельный коммит `cc07f4c`; мировой режим и глобус — следующий функциональный коммит. Для отмены используйте `git revert <хеш>` (от новых коммитов к старым). Чтобы посмотреть исходное состояние, сначала сохраните незавершённые изменения, затем `git switch backup/before-world-routes`; вернуться — `git switch design/editor-ui`. Пользовательские карты отдельно сохраняйте в JSON.
