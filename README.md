# Редактор карты России

Статический веб-редактор карты для подготовки графики к презентациям. Работает без бэкенда и после первой загрузки не требует внешних API.

## Что уже работает

- 89 субъектов РФ по статье 65 Конституции РФ;
- множественный выбор регионов и 450+ городов (все административные центры плюс города от 10 000 жителей), поиск, фильтрация и выбор целого федерального округа одной кнопкой;
- вкладка «Выбрано» со всем отмеченным, подсветка объекта на карте при наведении в списке и наоборот;
- однотонная заливка или градиент, редактируемые HEX-коды, положение цветовых точек, прозрачность и отдельный цвет выделения;
- настройка и отключение границ, подписей и городских маркеров (круг, квадрат, ромб, пин); размер подписей и контур текста регулируются; подписи регионов — все, что помещаются, либо только выбранные; подписи городов расставляются без наложений, при нехватке места отодвигаются с линией выноски, любую можно перетащить мышью (двойной клик возвращает на место);
- атласная равновеликая проекция, Меркатор и широкоугольная «Линза»;
- поворот карты (±45°), настройка силы линзового искажения;
- навигация как на бесконечной доске: масштаб колесом, кнопками или щипком на тач-экране и перемещение перетаскиванием, без сдвига интерфейса и без влияния на экспорт;
- отмена и повтор действий (⌘Z / ⇧⌘Z), защита от случайного сброса;
- рамка слайда 16:9 / 4:3 либо автоматическая обрезка по карте;
- экспорт в PNG ×2 (в файл или сразу в буфер обмена), SVG и PPTX; в PowerPoint карта помещается как векторный SVG с PNG-fallback, а все подписи (города и регионы) — как отдельные редактируемые текстовые объекты с родными атрибутами: шрифт, размер, цвет, выравнивание, контур (эффект «Свечение»);
- локальное автосохранение настроек в браузере;
- переносимый проект `*.project.json`: отдельное сохранение/открытие или автоматическое скачивание рядом с экспортом.

## Файл проекта и безопасность импорта

Проект — это только версионированные данные оформления, списки выбранных идентификаторов и ручные смещения подписей городов. В нём нет HTML, JavaScript, внешних URL или пользовательских файлов. Импорт:

- принимает только `.json` размером до 256 КБ;
- проверяет сигнатуру `map.kachkovenko.kontur` и поддерживаемую версию формата;
- валидирует типы, допустимые значения, числовые диапазоны и цвета (числа вне диапазона обрезаются до границы);
- переносит только заранее известные поля настроек;
- принимает только существующие ID регионов и городов, а смещения подписей — только для существующих городов и в разумных пределах;
- отклоняет служебные ключи прототипов и никогда не использует `eval` или динамическое выполнение кода.

Неизвестные поля не попадают в состояние приложения. Импортированный файл читается только в браузере и никуда не отправляется.

## Локальный запуск

Можно открыть `index.html` напрямую. Для поведения, идентичного публикации:

```bash
python3 -m http.server 8765
```

Откройте `http://localhost:8765`.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки.
2. В `Settings → Pages` выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`.
3. Там же в `Custom domain` сначала укажите `map.kachkovenko.com` и сохраните. Файл `CNAME` уже добавлен в проект.
4. После этого у DNS-провайдера создайте CNAME-запись: имя `map`, значение `<ваш-github-логин>.github.io`.
5. Когда GitHub подтвердит DNS и выпустит сертификат, включите `Enforce HTTPS` в настройках Pages.

Альтернатива — Cloudflare Pages или Vercel: импортируйте репозиторий как статический сайт, команда сборки не нужна, output directory — корень проекта. Затем добавьте `map.kachkovenko.com` в настройках доменов сервиса и подтвердите предложенную DNS-запись.

## Источники и ограничения

Перечень субъектов сверяется со статьёй 65 Конституции РФ. Геометрия основана на наборе `prokopenkoad42-creator/karta-rossii`, собранном из OSM/GADM и geoBoundaries; подробности и скрипт сборки находятся в исходном репозитории. Каталог городов дополнен Natural Earth Populated Places 1:10m (public domain). Используются D3, topojson-client и PptxGenJS.

Крым, Севастополь, Донецкая и Луганская народные республики, Запорожская и Херсонская области показаны в соответствии с законодательством РФ. Их принадлежность и границы международно оспариваются. Для коммерческого запуска рекомендуется провести отдельный аудит лицензии геометрии и, при необходимости, заменить её на набор с однозначной коммерческой лицензией.
